requeriment node v20.19.4. <br>
node index.js nombredelopt.opt<br>
Es necesario tener el fichero .opt en la raiz del proyecto<br>
Cuando acaba de extraer todo el contenido genera una carpeta map con el resultado en .obj tambien ./map/export contiene texturas en .dds<br>
se acepta como argumento el nombre del mapa a extraer. en caso de que no se especifique coge por defecto mp_dm_vertigo.opt <br>
